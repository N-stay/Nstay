# N STAY · Guest Guide

에어비앤비 게스트 안내 페이지입니다. 서버나 데이터베이스 없이 GitHub Pages로만 돌아갑니다.

- **안내 페이지**: https://n-stay.github.io/Nstay/
- **관리자 페이지**: https://n-stay.github.io/Nstay/admin/

## 관리자 페이지로 수정하기 (개발 지식 불필요)

1. https://n-stay.github.io/Nstay/admin/ 접속
2. 처음 한 번만 화면 안내대로 접속 키(GitHub 토큰)를 만들어 붙여넣기
3. 내용·사진 수정 → **미리보기**로 확인 → **저장하기**
4. 1~2분 뒤 안내 페이지에 자동 반영

수정할 수 있는 것: 숙소 기본 정보, Wi-Fi, 주소, 각종 링크, 코인세탁방 정보,
섹션별 안내 문구(한/영/일/중), 안내 사진(섹션마다 개수 제한 없음), 맛집·명소 카드.

저장을 누르면 이 저장소에 커밋 1개가 만들어집니다. 잘못 바꿨더라도 커밋 기록에서
언제든 되돌릴 수 있습니다.

## 파일 구조

```
index.html          안내 페이지 (내용은 아래 JSON에서 읽어옴)
data/content.json   모든 문구·사진 경로·링크가 담긴 유일한 데이터 파일
images/             안내 사진 (관리자 페이지에서 올리면 images/up/ 아래로 저장)
admin/index.html    관리자 페이지
```

`data/content.json` 의 `sections[].key` 는 화면의 특수 블록(Wi-Fi 박스, 버스 링크,
맛집·명소 카드, 세탁 지도 버튼, 배달 주소, Airbnb 버튼)을 붙이는 기준입니다.
섹션 순서를 바꿔도 따라가지만, **키 이름은 바꾸지 마세요.**
