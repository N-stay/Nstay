🔑 처음이신가요? 접속 키 만들기

아래 순서대로 한 번만 만들어두면, 다음부터는 이 화면 없이 바로 열립니다.

  1. 키 발급 페이지 열기 버튼을 누릅니다. (GitHub 로그인이 안 되어 있으면 로그인 먼저)
  2. Token name 에 아무 이름이나 적습니다. 예) N STAY 관리
  3. Resource owner 를 N-stay 로 바꿉니다. (가장 많이 실수하는 부분입니다)
  4. Expiration(사용 기간)을 정합니다. 예) 1 year
  5. Repository access 에서 Only select repositories 를 고르고 Nstay 를 선택합니다.
  6. Permissions → Repository permissions 에서 두 가지만 바꿉니다. 목록이 길지만 나머지는 손대지 않아도 됩니다.
    · Contents → Read and write (필수 — Read-only 로 두면 저장이 안 됩니다)
    · Pages → Read-only (선택 — 반영 상태 표시용)
    · Metadata 는 Read-only 로 이미 켜져 있습니다. 그대로 두세요.
  7. 맨 아래 Generate token 을 누르고, 나온 github_pat_... 을 통째로 복사합니다.
  8. 복사한 값을 아래 칸에 붙여넣고 접속을 누릅니다.
